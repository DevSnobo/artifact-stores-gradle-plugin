# Security policy

## Supported versions

Only the latest published release receives security fixes. Older versions are not maintained.

## Reporting a vulnerability

Do not open a public issue for a security problem.

Use GitHub's private vulnerability reporting:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Include the affected version, a reproduction, and the impact you expect.

If private reporting is unavailable, contact the maintainer through the repository owner profile
instead of posting details publicly.

You will receive an acknowledgement as soon as possible. Please allow time for a fix and a
coordinated disclosure before publishing details.
